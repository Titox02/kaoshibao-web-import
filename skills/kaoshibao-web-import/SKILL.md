---
name: kaoshibao-web-import
description: 从用户已授权的考试宝背题网页逐题提取题干、选项、正确答案和完整原解析，再生成本地练习页或接入现有练习网站；不主动调用考试宝接口，使用本地采集扩展、断点存档和一行校验摘要减少 token。
---

目标是完整原题与可复用导入文件，不改原答案、不总结原解析，不默认翻译/双语配对/生成 AI 解析。先确认用户授权的题库及导入目标，复用已有说明。

1. 读取 [references/capture.md](references/capture.md)，核对一次实际 DOM 选择器。用户启用 `extension/` 本地扩展后，题目直接存于扩展本机存储，不逐题经过模型。安装与网页操作必须遵守当前工具权限；不能用扩展绕过禁止的浏览器控制或访问限制。
2. 先预览、采 3 题并与原网页核对，再按小批次继续。只查看扩展进度摘要，不输出原解析、整页 HTML、题库 JSON、图片或脚本源码给模型。页面改版才重查选择器。发现验证/封禁/频率限制或关联不明确，停止并保留存档，不换号或绕过。
3. 导出 capture.json 后运行：

```sh
python3 "<技能目录>/scripts/finalize_capture.py" "<capture.json>" --out "<新的输出目录>"
```

图片已另存时加 `--media-map 图片映射.json`。脚本验证逐题连续性、总数、答案及内容指纹，输出一行统计；缺题默认拒绝导入。原解析确实缺失单独标记；图片没有本地化不能声称完整离线。

4. 本地目标：交付整个输出目录，打开 index.html 可练习。现有网站目标：只在该模式读取 [references/site-import.md](references/site-import.md)，先准备可审查的变更，再按目标站的既有授权发布。两个目标都要时复用同一份已验证数据，不重新采题。

提取仅通过可见 DOM 和原网页“下一题”按钮；扩展没有主动题库网络请求。原站响应正常按钮所发的请求无法避免，也不代表保证不触发风控。不读取 cookie、令牌、Vue/React 私有状态、隐藏题库缓存；不用 fetch/XHR/接口重放/并发跳题。

结束只报：已保存/总题数、答案与解析缺失、图片状态、产物位置和实际导入状态。明确区分“采集完成、校验完成、接入完成、已上线”，不把离线预览冒充线上导入。
